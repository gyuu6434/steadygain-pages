Chrome 확장 프로그램 · 인스타 레이더

개인정보처리방침

시행일: 2026년 9월 25일 · 운영자: 스테디게인(라핀)

이 방침은 Chrome 확장 프로그램 인스타 레이더에만 적용됩니다. 운영자는 이 확장 프로그램을 통해 사용자의 분석 데이터를 서버로 수집하거나 보관하지 않습니다. 다만 기능 제공을 위해 아래 정보를 사용자의 기기 안에서 처리합니다.

1. 기기 안에서 처리하는 정보와 목적

  • 사용자가 연 Instagram 프로필에 현재 로드된 공개 정보: 프로필 사용자 이름, 게시물·릴스 링크와 표시 정보, 팔로워·좋아요·댓글·조회 수 등. 화면의 분석 패널과 게시물 배지에 통계를 표시하고, 사용자가 선택하면 CSV 파일로 저장하기 위해 사용합니다.
  • 자동 채우기 중 스크롤·터치·키보드·포인터 입력의 발생 여부: 사용자가 직접 조작하면 자동 동작을 멈추기 위해 일시적으로 사용합니다. 키 입력 내용이나 방문 기록을 기록하지 않습니다.

2. 저장과 삭제

게시물 분석 정보는 현재 페이지의 브라우저 메모리에서 처리하며 확장 프로그램의 영구 저장소에 보관하지 않습니다. 페이지를 닫으면 이 분석 정보는 유지되지 않습니다. CSV 저장을 누른 경우 파일은 사용자의 기기에 내려받아지며 사용자가 직접 관리·삭제할 수 있습니다.

확장 프로그램 켜짐·꺼짐 설정은 Chrome의 기기 내 저장소에, 분석 기준 개수와 자동 채우기 설정은 Instagram 사이트의 브라우저 로컬 저장소에 저장합니다. 설정을 지우려면 확장 프로그램 데이터와 Instagram 사이트 데이터를 삭제할 수 있습니다.

3. 외부 전송과 공유

확장 프로그램은 위 분석 정보와 입력 감지 결과를 운영자 서버나 제3자에게 전송하지 않습니다. 판매, 광고 타기팅, 신용도 판단 또는 대출 목적으로 사용하지 않습니다. Instagram 웹사이트 자체의 통신에는 Instagram의 별도 방침이 적용됩니다.

4. 선택권과 문의

확장 프로그램은 Instagram에서만 작동합니다. 팝업에서 분석 기능을 끄거나 분석 패널에서 자동 채우기를 끌 수 있고, Chrome에서 확장 프로그램을 제거할 수 있습니다. 확장 프로그램 제거 후에도 Instagram 사이트 설정이 남아 있다면 해당 사이트 데이터를 별도로 삭제해 주세요.
